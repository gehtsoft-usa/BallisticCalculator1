public property TrajectoryCalculator.MaximumCalculationStepSize

Brief

The maximum step size of the calculation.

Declaration
C#
Measurement<DistanceUnit>  MaximumCalculationStepSize public get; public set;

Details

The default value is 1 m. Paired with the default midpoint integrator this runs about ten times coarser than the historical 10 cm Euler cap at equal accuracy. Set Integrator to Euler if you lower this for a fine Euler run.
