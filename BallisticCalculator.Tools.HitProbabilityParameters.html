class HitProbabilityParameters

Parents

object

Brief

The error inputs for a HitProbability estimate.

Public Properties

DistanceErrorPercent

The distance estimation error, as a one-standard-deviation percent of the range.

GroupSize

The shooter's group size (angular), taken directly as the per-axis standard deviation of the aim.

HorizontalPositionMultiplier

Widens the horizontal aim scatter relative to the fully supported group, for the shooting position.

MuzzleVelocityDeviationPercent

The muzzle velocity standard deviation, in percent of the muzzle velocity.

Seed

An optional random seed for reproducible runs; when null the run is non-deterministic.

Shots

The number of shots to simulate; the default is 1000.

TargetSize

The target size (diameter of a circular vital zone); a shot hits when it lands within half of it from the center.

VerticalPositionMultiplier

Widens the vertical aim scatter relative to the fully supported group, for the shooting position.

WindErrorPercent

The wind estimation error, as a one-standard-deviation percent of the wind speed.
