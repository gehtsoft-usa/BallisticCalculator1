static public method RadarDragTableFactory.Create

Brief

Creates a custom drag table from radar readings and the bullet's weight and diameter.

Declaration
C#
DrgDragTable  Create (IEnumerable<BallisticCalculator.Tools.RadarReading> readings, Measurement<WeightUnit> bulletWeight, Measurement<DistanceUnit> bulletDiameter, Atmosphere atmosphere = null, string name = null, Measurement<DistanceUnit>? bulletLength = null, string source = null)

Parameters
readings

The downrange velocity measurements.
bulletWeight

The bullet weight.
bulletDiameter

The bullet diameter.
atmosphere

The atmosphere the data was measured in; when null, a sea-level standard atmosphere is used.
name

An optional name for the resulting ammunition entry.
bulletLength

The optional bullet length. It is not used by the drag curve, but it is required for the spin drift and the aerodynamic jump, and it is stored in the drg file.
source

The optional description of the data origin. When it is not specified, the entry is marked as radar data.

Details

Readings are sorted by distance; velocity must strictly decrease with distance. At least three readings are required.
