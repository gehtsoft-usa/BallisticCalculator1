public constructor DrgDragTable.DrgDragTable

Brief

Constructs a custom table from measured drag points and the bullet metadata.

Declaration
C#
  DrgDragTable (DragTableDataPoint [] points, string name, Measurement<WeightUnit> bulletWeight, Measurement<DistanceUnit> bulletDiameter, Measurement<DistanceUnit>? bulletLength = null, string source = null, Measurement<VelocityUnit>? muzzleVelocity = null)

Parameters
points

The drag points. They must be sorted in ascending order by the Mach number and at least two points are required.
name

The name of the projectile.
bulletWeight

The bullet weight.
bulletDiameter

The bullet diameter.
bulletLength

The optional bullet length. It is not used by the drag curve, but it is required for the spin drift and the aerodynamic jump.
source

The optional description of the data origin.
muzzleVelocity

The optional muzzle velocity of the reference load. When it is not specified, a placeholder of 500 meters per second is used.

Details

The parameters are exactly the values a drg file header carries, so a table built this way and saved keeps all of its metadata.
