class DrgDragTableFactory

Parents

object

Brief

Synthesizes a custom drag table from a standard base drag curve and an effective ballistic-coefficient-vs-Mach profile.

Details

The synthesized curve is the projectile's own drag coefficient, Cd(M) = Cd_base(M) / BC(M) * SD, where BC(M) is interpolated from the supplied knots and SD is the sectional density of the bullet. That is the same quantity a drg file stores, so the result is interchangeable with a table loaded by DrgDragTable or built by RadarDragTableFactory: it survives a Save and Open round trip unchanged, and it is run with the form factor of one that the factory writes into the ammunition it hands back.
