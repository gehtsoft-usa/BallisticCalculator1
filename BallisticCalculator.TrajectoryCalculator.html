class TrajectoryCalculator

object

Brief

The calculator for the projectile trajectory.

Details

Thread safety: a single instance is safe for concurrent use from multiple threads, provided its configuration (Integrator and MaximumCalculationStepSize) is not changed while calculations are running. Configure the instance once, then share it: the calculation methods keep no per-call state on the instance, all inputs are treated as read-only, and the standard drag tables are cached as thread-safe singletons. To vary the configuration per thread, use a separate instance per thread instead.
